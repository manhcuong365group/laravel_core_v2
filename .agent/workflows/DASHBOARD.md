# 🚀 Bảng Điều Khiển Antigravity (Quick Dashboard)

Chào mừng bạn đến với hệ thống hỗ trợ lập trình **Antigravity Kit**. Đây là bảng tra cứu nhanh các mã lệnh điều khiển bằng tiếng Việt giúp bạn thao tác hiệu quả trên CLI.

---

## 🛠️ Quy Trình Làm Việc Cốt Lõi (Core Workflow)

Khi bắt đầu một tác vụ mới, hãy tuân thủ quy trình 3 bước sau để đạt hiệu quả tối ưu:

### 💎 Quy Trình Chuẩn (Master Lifecycle)

> **Lệnh:** `/standard-flow [ý tưởng của bạn]`  
> **Mục tiêu:** Tự động điều hướng bạn qua 5 giai đoạn: Khám phá -> Lập kế hoạch -> Thực thi -> Kiểm định -> Triển khai.
> **Lời khuyên:** Hãy bắt đầu mọi tính năng mới bằng lệnh này để đạt hiệu quả cao nhất.

### 🟢 Bước 1: Lập Kế Hoạch (Planning)

> **Lệnh:** `/plan [yêu cầu của bạn]`  
> **Mục tiêu:** Phân tích yêu cầu, chia nhỏ task và tạo file `PLAN.md`.  
> **Lưu ý:** Bước này chưa viết code, chỉ để thống nhất phương pháp làm việc.

### 🔵 Bước 2: Thực Hiện (Implementation)

> **Lệnh:** `/create` hoặc `/enhance [tên task]`  
> **Mục tiêu:** Bắt đầu viết code dựa trên kế hoạch đã duyệt.  
> **Lưu ý:** Sử dụng `/create` cho tính năng mới hoàn toàn, `/enhance` để cập nhật code cũ.

### 🔴 Bước 3: Kiểm Tra (Validation)

> **Lệnh:** `/status`  
> **Mục tiêu:** Xem báo cáo tiến độ, các file đã sửa và Agent nào đang chạy.

## 📋 Danh Sách Tất Cả Mã Lệnh (Workflow List)

| Mã Lệnh          | Chức Năng           | Khi Nào Nên Dùng?                                      |
| :--------------- | :------------------ | :----------------------------------------------------- |
| `/brainstorm`    | Động não / Socratic | Khi bạn chỉ có ý tưởng mờ nhạt, cần AI hỏi để làm rõ.  |
| `/plan`          | Lập kế hoạch        | BẮT BUỘC trước khi thực hiện các task phức tạp.        |
| `/create`        | Tạo mới             | Xây dựng module, ứng dụng hoặc tính năng từ con số 0.  |
| `/enhance`       | Nâng cấp            | Sửa đổi, tối ưu hoặc thêm tính năng vào code hiện tại. |
| `/ui-ux-pro-max` | Thiết kế VIP        | Khi cần giao diện đẹp xuất sắc (Premium Design).       |
| `/orchestrate`   | Điều phối đa năng   | Cho các task siêu khó, cần phối hợp nhiều Agent.       |
| `/debug`         | Sửa lỗi             | Quy trình 5 bước để tìm và diệt Bug tận gốc.           |
| `/test`          | Kiểm thử            | Viết Unit Test, E2E và kiểm tra độ phủ (Coverage).     |
| `/preview`       | Xem trước           | Chạy server ảo để xem kết quả trên trình duyệt.        |
| `/status`        | Trạng thái          | Xem tiến độ dự án và Agent đang hoạt động.             |
| `/deploy`        | Triển khai          | Kiểm tra bảo mật và tối ưu trước khi xuất bản.         |

## 💡 Mẹo Sử Dụng CLI Hiệu Quả

1.  **Gõ phím tắt:** Thay vì gõ cả lệnh, bạn có thể gõ `/pl` (cho `/plan`), `/st` (cho `/status`) để CLI tự lọc.
2.  **Duyệt kế hoạch:** Luôn kiểm tra file `PLAN.md` trước khi để AI viết code hăng say.
3.  **Tập trung vào Workflow:** Hãy ưu tiên dùng các lệnh `/` thay vì ra lệnh bằng văn bản tự do để AI đi đúng quy trình kỹ thuật.
